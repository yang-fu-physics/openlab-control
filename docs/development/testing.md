# 怎样检查测量模块

测试的目的不是证明“永远不会出错”，而是尽早发现明显问题。先在不连接仪表时检查，再做
低风险真机检查。

## 先运行教学模块测试

```powershell
.\.venv\Scripts\python.exe -m unittest discover `
  -s plugin_templates\measurement-modules-repository\tests -v
```

这些测试会检查教学模块能否启动、应用设置、逐通道测量、报告超量程并安全关闭。完整例子在
`plugin_templates/measurement-modules-repository/tests/test_tutorial_resistance.py`。

## 每个模块至少检查这些情况

- 正常 Enable 和 Disable；
- 连接进行到一半时失败，仍能安全关闭；
- 仪表型号不正确时拒绝继续；
- 没有点击 Apply Settings 时拒绝测量；
- 每个通道只写自己的列；
- 未测量和出错的电阻值保持空白；
- 正常、超量程、仪表保护限制和其他状态码；
- Pause 和 Stop 能在等待步骤中生效；
- 重复关闭不会报错；
- 程序结束或出错时，输出按模块设置安全关闭。

## 单独检查仪表命令

不接真实仪表，用假的 VISA 或串口连接检查：

- 先确认仪表型号，再发送设置命令；
- 设置、读回、触发和读取的顺序正确；
- 每种量程和状态都能正确解释；
- 空返回、乱码和无效数字会被发现；
- 写命令等待超时后不会盲目重发；
- 一个资源关闭失败时，其他资源仍会继续释放；
- 每次读取都有等待上限。

## 检查设置窗口

- 保存值载入后仍能原样取出；
- Load SEQ 不会自动连接仪表或应用设置；
- 状态更新只改变显示；
- 初始宽度不出现横向滚动条；
- 下拉列表没有展开时，滚轮不会误改数值。

## 修改主程序后运行完整测试

普通模块通常不需要修改主程序。如果确实修改了主程序，再运行：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

## 最后才连接真实仪表

1. 先不接样品，只读取型号和状态。
2. 在仪表面板上设置最低风险的限流、限压或量程。
3. 每发送一次设置，立即从仪表读回确认。
4. 人工测试 Stop、断线和等待超时。
5. 确认硬件联锁和人工急停有效。
6. 保存去除隐私信息的命令日志和测试结果。
7. 完成这些检查前，模块保持 Beta，不要无人值守运行。
