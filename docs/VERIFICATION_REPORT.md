## 当前说明

先前 0.10.3 基线报告的测试数量、包体和示例模块布局已被本轮架构改动取代，不能继续作为
当前候选版本证据。本轮新增了：

- 每设备独立进程、主控/只读角色和一分钟读链路恢复窗；
- Device Plugin 与 Measurement Module 的首次内容指纹信任；
- 受限 JSON IPC；
- 完全离线、精确哈希、按扩展隔离并验证完整性的依赖 runtime；
- 核心扩展目录默认空，以及两个独立扩展仓库模板。

最终完整测试、源码冒烟、Windows 构建、干净目录打包版冒烟、进程退出、文件版本、包
体积、SHA-256 和 Authenticode 结果将在发布提交前重新写入本文件。未完成这些检查前，
不得把本候选描述为已验证或可用于真实仪表。
