# 用 Data Browser 查看 DAT

Data Browser 可以打开任意 DAT，不要求它属于当前 SEQ，也不会改变正在运行的实验文件。

## 打开文件

1. 点击 **Graph → Data Browser**。
2. 点击 **Open DAT**。程序会直接打开 Windows 文件选择窗口。
3. 选择任意 `.dat` 文件；也可以把 DAT 拖到主窗口。

窗口只跟踪你明确打开的文件。文件继续追加时会自动刷新；临时无法读取时会等待并重试，
不会因此增加仪表查询次数。需要立即重新读取时点击 **Reload**。

## 选择曲线

在图区域右键可以：

- 选择 X 列；
- 勾选一个或多个 Y 列；
- 选择 Overlay（多条曲线放在同一图）或 Stacked（分图、共用 X）；
- 切换 X/Y 对数坐标；
- Reset Zoom。

鼠标拖框可以放大。双击离鼠标最近的数据点，会显示该行的完整字段。

## 时间与刻度

能确认来源的 `Timestamp(s)` 或 `Time Stamp (sec)` 会显示成实际日期和时间。老 DAT 若没有
足够信息判断时间起点，则保留原始秒值，避免显示错误日期。

普通数值轴使用 `1 / 2 / 5 × 10ⁿ` 一类整齐刻度；时间轴按毫秒、秒、分钟、小时或日期
对齐。缩放只改变显示范围，不修改 DAT。

## 保存显示方式

点击 **Save PLT** 会在 DAT 旁保存同名 `.plt`，记录 X/Y、布局和坐标类型。以后再次打开
该 DAT 时会自动恢复；`.plt` 不包含测量数据，可以删除后重新设置。
