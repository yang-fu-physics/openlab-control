# 用 Data Browser 查看 DAT

Data Browser 读取 OpenLab DAT 的 `[Data]` 格式，不要求文件属于当前 SEQ，
也不会改变正在运行的实验文件。不自动判断其他格式，不导入 CSV 或普通文本。
每次打开都会创建一个独立窗口，因此可以同时查看多个文件。

## 打开文件

1. 当前 Run 已有数据文件时，可点击左侧数据区的 **View**，新窗口会直接载入该文件。
2. 点击 **Graph → Data Browser** 会打开一个空白的新窗口，再用 **Open DAT** 选择任意
   `.dat`；也可以把 DAT 拖到主窗口。
3. 重复以上操作可创建多个窗口，每个窗口保持自己的文件、曲线和 `.plt` 设置。

每个窗口只跟踪自己打开的文件，每 750 ms 检查一次变化，文件读取在后台进行。
自动刷新遇到尚未写完的最后一行时，保留上一份完整视图并等待重试，
不会因此增加仪表查询次数。需要立即重新读取时点击 **Reload**。

## 选择曲线

在图区域右键可以：

- 选择 X 列；
- 勾选一个或多个 Y 列；
- 选择 Overlay（多条曲线放在同一图）或 Stacked（分图、共用 X）；
- 切换 X/Y 对数坐标；
- Reset Zoom。

鼠标拖框可以放大；单击数据点会标记它。双击打开该原始行的完整字段，
用 **Previous Point / Next Point** 在同一曲线的可见点之间移动。
右键 **Browse Raw File** 可只读查看原文，不受筛选影响。大数据曲线仍使用全部可绘制点，
只在点多时隐藏普通点标记。

## 筛选

点 **Data Filter…**，可设置一个 Time 条件和四个数值条件。各条件同时满足才保留该行，
Min 和 Max 都含边界；留空表示不限制该端。Time 行有可靠时间基准时用日期时间，
否则用经过秒数或 `HH:MM:SS`。筛选只改变本窗口显示，不修改 DAT。

## 时间与刻度

能确认来源的 `Timestamp(s)` 或 `Time Stamp (sec)` 会显示成实际日期和时间。老 DAT 若没有
足够信息判断时间起点，则保留原始秒值，避免显示错误日期。

普通数值轴使用 `1 / 2 / 5 × 10ⁿ` 一类整齐刻度；时间轴按毫秒、秒、分钟、小时或日期
对齐。缩放只改变显示范围，不修改 DAT。

## 保存显示方式

显示设置会自动保存到 DAT 旁的同名 `.plt`，也可以点 **Save PLT** 手动保存。
它记录 X/Y、布局、坐标类型、缩放和筛选，下次打开自动恢复；不包含测量数据。
没有筛选状态时仍写旧版 v2；有筛选状态时写 v5。
