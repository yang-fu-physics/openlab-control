# 用 Data Browser 查看数据

**Data Browser** 可以打开任意 `.dat` 文件（包括正在跑的实验或历史数据），不会修改原始数据，也不会影响当前正在运行的 SEQ。你可以同时打开多个独立的 Data Browser 窗口对比不同曲线。

数据浏览窗口独立于主窗口，可移动到其他屏幕，不受底部仪表区限制。缩窄窗口后，工具栏中放不下的操作可通过右侧展开按钮访问。

## 打开数据文件

有三种快捷方式：

1. **看当前正在跑的实验**：直接点击主窗口左侧数据区的 **View**，会弹出新窗口并自动加载当前 Run 的 DAT。
2. **看任意历史文件**：点击顶部菜单 **Graph → Data Browser** 打开新窗口，再点 **Open DAT** 选择文件。
3. **拖放打开**：直接把 Windows 资源管理器里的 `.dat` 文件拖进主窗口。

每个窗口只盯住自己打开的那个文件。如果文件正在持续追加新行，图表会自动刷新（不增加任何仪表通讯）；想立即手动刷新，点击工具栏 **Reload**。

## 常用交互操作

在图表空白处**点击鼠标右键**可以：

- 选择 **X 轴**数据列；
- 一次勾选一个或多个 **Y 轴**数据列，确认后同时绘制；
- 切换布局：**Overlay**（多条曲线叠在同一坐标系）或 **Stacked**（上下分图、共用 X 轴）；
- 独立开关 **X / Y 对数坐标（Log）**；
- 点击 **Reset Zoom** 恢复全貌。

常用鼠标操作：

- **左键拖框**：局部放大；
- **双击曲线附近**：弹出离鼠标最近数据点的完整原始行信息。

## 时间轴与坐标刻度

- 对于能确认时间基准的 `Timestamp(s)` / `Time Stamp (sec)` 列（支持 OpenLab DAT 和 Quantum Design DAT），在线性轴上会自动换算成直观的日期和时间；遇到无法确定时间起点的老文件，则保留原始秒数，避免显示错误日期。
- 双击查看单点详情时，顶部摘要会给出可读的完整日期时间，下方字段表仍保留文件里的原始数值。
- 数值轴自动使用 `1 / 2 / 5 × 10ⁿ` 整齐刻度，时间轴自动按毫秒、秒、分钟、小时或日期对齐。

## 自动记住视图设置（`.plt`）

点击 **Save PLT** 后，程序会在数据文件旁边生成一个同名的 `.plt` 文件，记录你选的 X/Y 列、Overlay/Stacked 布局、对数坐标和缩放范围。下次打开这个 DAT 时会自动恢复视图。`.plt` 里不含实验数据，随时可以删掉重配。
