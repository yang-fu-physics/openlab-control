# System Instrument Log

从工具栏、Instrument 菜单或 Graph 菜单打开 **System Log…**。

1. 选择 `.log` 文件路径。默认放在当前 DAT 所在目录；尚未选择 DAT 时使用当前数据目录。
2. 选择记录间隔：默认 **30 s**，只接受正整数秒。
3. 按系统仪表实例分页勾选记录项，每页提供 Select All / Select None。同型号的不同实例各占一页。
4. 点击 **Start Log**，立即记录一行已有缓存，此后按所选间隔持续记录；点击 **Stop Log** 停止。
5. 点击日志文件路径右侧的 **View**，可直接用 **Data Browser** 打开当前 `.log` 文件查看曲线（记录过程中也可随时点开并自动刷新）。

日志在空闲、手动调温、SEQ 运行和暂停期间都可以继续记录。关闭设置窗口不会停止记录；退出程序会关闭日志文件。记录中锁定路径、间隔和记录项，停止后可以修改。

记录器只拿已有缓存值，不发送查询、不触发测量，也不改变仪表轮询频率。缓存未更新时会记录相同值，Reading Age 可以辅助判断读数新鲜度。22C 可选主控温度、目标、速率、动作与稳定状态、CH B 温度、加热输出、Heater Range 等。时间戳自动记录，使用程序配置的 LabVIEW 1904 或 Unix 时间基准。

文件不存在时创建，同名时续写，不自动编号或覆盖。续写要求记录项、列顺序和时间基准一致；不一致时提示选择原记录项或其他文件。再次 Start 会立即写入当前缓存，时间戳连续使用绝对时间，允许改变记录间隔。`.log` 使用带 `[Header]` / `[Data]` 的 CSV 文本格式。

写入失败时停止该 Log 并显示 Warning，不中止 SEQ。运行目录里的 `instrument_status.dat` 自动快照仍按原配置记录；手动 System Log 的路径、间隔和记录项独立设置。
