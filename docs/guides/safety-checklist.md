# 真实仪表安全清单

这份清单是进入真实仪表测试前的最低门槛，不是免责条款。任何一项无法确认，都应停止自动
控制并回到只读或仿真模式。

## 连接前

- [ ] 核对仪表完整型号、选件、固件和接口类型。
- [ ] 仪表本机限流、限压、限温、磁体保护和联锁已经人工设置。
- [ ] 明确人工急停位置和断电后的设备行为。
- [ ] 样品与测试负载能承受最坏输出。
- [ ] 软件配置的地址和上下限不包含实验室秘密或误连其他设备的风险。

## connect / open

- [ ] 导入和构造阶段没有 I/O。
- [ ] 会话使用有限 timeout。
- [ ] 第一条操作是身份/状态读取，而不是配置写入。
- [ ] 型号或固件不匹配时 fail-closed。
- [ ] 保存设置只加载到界面，不自动 Apply。
- [ ] 部分初始化失败后仍能安全 close/disconnect。

## 设置与写命令

- [ ] 核心、插件/模块和仪表本机三层都有限制。
- [ ] 后端再次验证单位、有限数、符号、量程和当前状态。
- [ ] Apply 后读取关键配置并比较。
- [ ] 写 timeout 被视为结果不确定，不自动重放。
- [ ] 多条设置命令失败时能识别仪表可能处于部分配置状态。

## 测量

- [ ] 每个通道切换、pause、dwell、arm 和 trigger 顺序来自对应手册。
- [ ] 每个 I/O timeout 为总操作超时预留安全清理时间。
- [ ] 超量程、compliance、坏状态字和损坏响应分别测试。
- [ ] 数据异常留空测量值并写模块数字状态码。
- [ ] 通讯、输出或联锁状态无法确认时抛 Error，而不是仅写状态码。
- [ ] rawdata 只含有限测量值，行与正式 DAT 对齐。

## Pause / Stop / Error

- [ ] 长循环和相邻 I/O 之间调用 `api.checkpoint()`。
- [ ] 人工验证 Pause 不会造成意外输出变化。
- [ ] completed、stopped、error 三种 `run_end` 都执行模块定义的收尾。
- [ ] 若允许跨 SEQ 保持输出：默认仍关闭；保持前读回输出和关键设置；下一次
  `run_start` 不产生短暂掉电；Apply、Disable、退出和测量异常仍关闭。
- [ ] Stop/Error 后温度和磁场保持当前状态。
- [ ] `close` 可重复调用，并在部分初始化后工作。
- [ ] 即使一个仪表关闭失败，也继续释放其他会话。

## Device Plugin 特别检查

- [ ] `poll()` 返回当前值、目标、速率和活动状态，时间戳使用单调时钟。
- [ ] `hold()` 使用新鲜读回，绝不代入缓存零或猜测值。
- [ ] 读链路重连后读取真实 target/rate，不自动重放旧写命令。
- [ ] 恢复窗结束后进入 Faulted，并阻止后续控制。
- [ ] 同类设备只有一个 primary，其余保持只读。

## 真机放行

- [ ] 先以只读方式测试身份和状态。
- [ ] 再用最低风险输出和测试负载执行单次命令。
- [ ] 人工制造 timeout、断线、Stop 和 Error。
- [ ] 对照仪表面板确认软件报告与真实输出一致。
- [ ] 保存脱敏命令顺序、读回和测试结果。
- [ ] 未完成验证时继续标注 Beta，并禁止无人值守。

!!! danger "进程退出不等于仪表安全"

    worker 被终止只能证明本机进程结束，不能证明外部仪表已关闭输出。最终安全必须由仪表
    本机保护、联锁和人工急停保证。
